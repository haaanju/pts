# PTS — Personal Token System

Design tokens written in [DTCG](https://www.designtokens.org/) format and built with [Terrazzo](https://terrazzo.app).
Every page here is generated from `packages/tokens/src` through `pts.resolver.json`, so it always matches the source.

## Tiers

| Tier | Files | Role |
|------|-------|------|
| primitive | `primitive/*.tokens.json` | Raw values: `dimension`, `palette`, `typeface`, `weight`, `ratio`, `duration`, `easing` |
| semantic | `semantic/*.tokens.json` | Intent: `space`, `color`, `text`, `shadow`, `size`, `motion`, … Aliases primitives |

## Themes

Color and shadow differ between **light** and **dark**. Those pages show both side by side.
In CSS, light values live on `:root`; dark values apply under `prefers-color-scheme: dark` or `[data-theme="dark"]`.

## Usage

```css
@import "@pts/css";

.button {
  height: var(--size-control-md);
  padding: 0 var(--space-400);
  border-radius: var(--radius-md);
  background: var(--color-background-primary);
  color: var(--color-foreground-on-primary);
  font: var(--text-label-md);
}
.button:hover { background: var(--color-background-primary-hover); }
.button:focus-visible {
  outline: var(--focus-ring-width) solid var(--color-border-focus);
  outline-offset: var(--focus-ring-offset);
}
```

## Accessibility

Every foreground meets **4.5:1** on the background it is paired with, and borders and solid fills meet **3:1** against the page, in both themes.
`npm run check` enforces this on every commit.
