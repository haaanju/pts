# Semantic color

Named **property → role → emphasis → state**: `color.background.danger-hover`.

- `foreground.on-X` sits on `background.X` (and its `-hover` / `-pressed`).
- Other foregrounds sit on the page backgrounds (`default`, `default-hover`, `default-pressed`, `subtle`).
- Text needs **4.5:1**, borders and solid fills **3:1**. `disabled`, `border.default` and `background.overlay` are exempt.

The ratios below use the paired background (foregrounds) or `background.default` (borders). `npm run check` tests every pairing.
