<Section title="Usage" lead="A web component, so it works in any framework. Load the fonts and tokens once, then import the element to define it.">
  <Source
    language="js"
    dark
    code={`// app entry (with a bundler)
import "@pts/web/fonts.css";
import "@pts/web/tokens.css";
import "@pts/components/button.js"; // defines <pts-button>`}
  />
  <Source
    language="html"
    dark
    code={`<pts-button variant="primary" type="submit">Save</pts-button>
<pts-button>
  <svg slot="start" aria-hidden="true">…</svg>
  Add
</pts-button>
<pts-button label="Close"><svg slot="start" aria-hidden="true">…</svg></pts-button>
<pts-button variant="danger" loading>Delete</pts-button>`}
  />

  - `variant`: `primary` (the main action, at most one per group), `secondary` (default), `ghost`, `danger`.
  - `size`: `sm`, `md` (default), `lg`. `full-width` fills the container.
  - `type`: `button` (default), `submit`, `reset`. The element is form-associated, so `submit` and `reset` act on the surrounding form.
  - `disabled` and `loading` ignore clicks but stay focusable (`aria-disabled`, `aria-busy`); loading keeps the width.
  - Icons go in the `start` and `end` slots. A button with no text is icon-only and needs `label`, its accessible name.
</Section>
