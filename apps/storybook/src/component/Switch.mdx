<Section title="Usage" lead="A web component, so it works in any framework. Load the fonts and tokens once, then import the element to define it.">
  <Source
    language="js"
    dark
    code={`// app entry (with a bundler)
import "@pts/web/fonts.css";
import "@pts/web/tokens.css";
import "@pts/components/switch.js"; // defines <pts-switch>`}
  />
  <Source
    language="html"
    dark
    code={`<pts-switch name="notifications" checked>Notifications</pts-switch>
<pts-switch label="Wi-Fi"></pts-switch>
<pts-switch disabled>Location</pts-switch>`}
  />

  - The label comes first and the track after it. Given a width, the switch puts its track at the end, as in a settings row.
  - `checked` turns it on; the attribute is the starting state, which a form reset returns to. Clicking the label or the track, or Space, toggles it and fires `change`.
  - The element is form-associated: with a `name`, the form submits `value` (`on` by default) while it is on, and nothing while off.
  - `disabled` ignores clicks and keys but stays focusable (`aria-disabled`).
  - A switch with no text needs `label`, its accessible name.
</Section>
